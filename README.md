# 📊 Proyecto: Predicción de Notas de Estudiantes usando Regresión Lineal

## 1. Descripción del Proyecto

El objetivo de este proyecto es predecir la **nota final** de un estudiante en función de ciertos factores como **horas de estudio**, **participación en clase** y **cantidad de tareas entregadas**.

Se utiliza **regresión lineal**, un algoritmo de *Machine Learning supervisado*, que permite predecir un valor continuo (en este caso, la nota final) basándose en la relación lineal entre las variables de entrada.
